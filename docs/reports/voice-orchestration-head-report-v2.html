5分层核心契约

head 只说语义；主对接 agent 收敛为稳定指令；凭证经口语通道逐字回显，机器侧可校验。

用户语音→ head 抽取语义指令→ dispatch_intent→ 主对接 agent 受理（回执 ref）→ 稳定指令 → manager 级 agent→ 编排器 skill 选 A/B 车道→ ADE 执行 fan-out→ 终稿回信（[ref:] 匹配）→ head 二次播报（凭证逐字）
契约内容
语义指令（head 出口）dispatch_intent(raw_intent) 单字符串，自包含、指代全展开；head 零 schema 压力
受理回执（phase-1）{"status":"accepted","run_id","ref","credentials":["【凭证VH-…】"]}——立即返回，ref 原样口语播报（丢失即事故）
稳定指令（主对接 agent 出口）语义收敛为结构化指令（agent 类型 + 自包含 goal + 依赖），幂等可重放；下发 manager 级 agent
终稿（phase-2）"Agent Final Message":\n\n<done body> 前缀 → 注入 head 上下文 → 二次播报；编排输出是权威凭证通道，head 口语是摘要
凭证约定【凭证…】 定界符逐字回显（12/12 麻雀泛化验证）
回信匹配（防自匹配）[ref:] 命中 ∧ seq > intent_seq ∧ from == 对接 agent 句柄——否则会把自己发的指令当回信（live 实锤）
打断 / 取消本地播报打断从不取消远程执行；显式 cancel_run 才取消（V6 验证：取消后无迟到终稿）；fail-dispatch 仅认 ctx_ 句柄，杀本地 phase-2 即权威取消
